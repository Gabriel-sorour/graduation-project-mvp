🍽️ Chef Sage API

Complete documentation for backend endpoints (Laravel)

🔐 Authentication

POST /api/register
Register a new user
POST /api/login
Login and receive token
POST /api/logout Auth
Logout user (revoke token)
GET /api/me Auth
Get current logged-in user details
POST /api/refresh Auth
Refresh authentication token

🍲 Recipes & Search

GET /api/recipes
Get all recipes
GET /api/recipes/{id}
Get a single recipe by ID
GET /api/recipes/top-loved
Get top loved recipes
POST GET /api/recipes/search
Search recipes (supports both GET and POST)
POST /api/recipes
Create a new recipe (User submission)

🥕 Pantry & Ingredients

GET /api/ingredients
Get all available ingredients list
GET /api/pantry Auth
Get user's pantry items
GET /api/pantry/lang Auth
Get user's pantry items (Localized)
POST /api/pantry Auth
Add item to pantry
DELETE /api/pantry/{id} Auth
Remove item from pantry
DELETE /api/pantry/{id}/sync Auth
Remove item and sync

🛒 Shopping List

GET /api/shopping-list Auth
Get shopping list items
POST /api/shopping-list Auth
Add item to shopping list
PATCH /api/shopping-list/{id} Auth
Toggle item status (checked/unchecked)
DELETE /api/shopping-list/{id} Auth
Delete item from shopping list
POST /api/shopping/migrate Auth
Migrate shopping list items to pantry

❤️ Favorites

GET /api/favorites Auth
Get user favorite recipes
POST /api/favorites Auth
Add recipe to favorites
DELETE /api/favorites/{recipe_id} Auth
Remove recipe from favorites

🤖 AI & Smart Features

POST /api/smart-assistant Auth
Smart Chat Assistant (Authenticated)
GET /api/recipes/match-pantry Auth
Find recipes matching pantry ingredients
GET /api/recipes/surprise-me Auth
Get a random "Surprise Me" recipe

📂 Categories

GET /api/getAll Auth + CheckPass
Get all categories
POST /api/create Auth + CheckPass
Create new category
POST /api/update Auth + CheckPass
Update category
POST /api/delete Auth + CheckPass
Delete category

🛠️ Utilities

POST /api/uploadimage
Upload an image
GET /api/ping
Health check (Pong)
GET /api/test
Test connection

🛡️ Admin Panel (Prefix: /admin)

Requires auth:sanctum and admin middleware.

GET /api/admin/stats Admin
Dashboard Statistics

Manage Recipes

GET /api/admin/recipes Admin
Get/Filter Admin Recipes
GET /api/admin/recipes/options Admin
Get Recipe Filter Options
POST PUT DEL /api/admin/recipes/{id}
CRUD Operations for Recipes

Manage Users

GET /api/admin/users
List all users
POST PUT DEL /api/admin/users/{id}
CRUD Operations for Users

Manage Ingredients

GET /api/admin/ingredients
List all ingredients
POST PUT DEL /api/admin/ingredients/{id}
CRUD Operations for Ingredients
